# Getting Started

Use this guide to get oriented and run the CLI.

- Quickstart CLI: see [../cli_quickstart.md](../cli_quickstart.md)
- Dev setup: see [../dev_setup.md](../dev_setup.md)
- Talk to Mythscribe (MVP):
  1. Set `OPENAI_API_KEY`
  2. `cargo run -- chat mythscribe --no-stream`
  3. Type your question and press Enter. `exit` to quit.
