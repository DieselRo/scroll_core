# System Overview

Scroll Core blends narrative constructs with a structured runtime:

- Constructs: pluggable agents with metadata and invocation logic
- Invocation Engine: frames context and routes to constructs
- Context Frame Engine: builds layered context from archive and session
- Sessions & DB: persists chat and invocation events
- Trigger Loom: background heuristics/emotions that adapt behavior
- Artifacts & Archive: content-addressed records and files
- CLI: rituals to validate/write/seal/index scrolls
