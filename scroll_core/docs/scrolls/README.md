# Scroll Archive (Canonical)

This directory contains the canonical scrollbooks, lore, and specs that ship with Scroll Core. Runtime code defaults to this location (`SCROLL_CORE_ARCHIVE_DIR` can override). If you want to experiment with a different archive, copy or mount it under the root-level `scrolls/` directory and adjust `SCROLL_CORE_ARCHIVE_DIR` accordingly.

Structure mirrors the historical archive: `shared/`, `system/`, and supporting docs. Follow the scroll governance rules documented in `docs/alignment/MASTER_PLAN.md` and related scrollbook governance files when editing lore.
